## 风险与后续观察

- 删除检索节点使相关模型失去知识库上下文。2026-06-05 的历史记录显示，网站助手此前移除检索后曾失去部分站内语义与功能感知；本次基础功能测试通过，但不能证明所有场景的回答质量不变。
- 无 API Key 的备课助手副本没有直接运行验收；如果以后为它配置 Key，应先用独立样例做一次回复检查。
- 如出现特定应用的答案质量下降，可用对应备份标签只回滚受影响的工作流；不要恢复或清理整个 Dify 数据库。
- 延迟收益未做同输入、同模型条件下的对照测量，不应把单次请求时长当作稳定提速幅度。
