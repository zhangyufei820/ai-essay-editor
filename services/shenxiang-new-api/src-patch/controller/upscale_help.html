图片高清放大

先选择原图，再选择放大方式和倍数。提交前查看输出尺寸与人民币费用。

选择精准还是创意

模式适用图片特点
精准放大照片、产品图、标志、界面截图尽量忠实原图。支持艺术与插画、真实照片、照片降噪三种处理风格。
创意放大插画、概念图、营销素材、人工智能生成图片可通过提示词和滑杆补充纹理与细节，可能改变原图内容。

图片与倍数限制

  • 支持静态 JPG、PNG、WebP；不支持动态图、GIF、HEIC、AVIF、TIFF 等格式。
  • 每边需为 16 至 10,000 像素。照片方向按文件中的方向信息校正。
  • 本地上传或图片编码方式最大 10MB；公开 HTTPS 图片链接最大 75MB。链接应无需登录，且不能在处理过程中替换内容。
  • 支持 2、4、8、16 倍，最终输出总像素不能超过 101,200,000。尺寸过大时，对应倍数会不可用。
  • 精准放大的“真实照片”和“照片降噪”仅支持 2 倍；更高倍数请选择“艺术与插画”。
  • 优先使用原始文件，避免事先反复压缩或缩小；原图超过限制时再调整。

调整参数

创意放大

“优化方向”用于选择图片题材；“引擎”可选择自动、插画柔和、写实锐利或均衡细节。提示词为可选项，最长 2000 个字符。人工智能生成图片可尝试复用原来的提示词。

参数范围说明
创意程度−10 至 10，默认 0越高，补充的新细节越多。
细节层次−10 至 10，默认 0调整清晰度与明暗细节层次。
原图相似度−10 至 10，默认 0越高，越接近原图。
细节繁复度−10 至 10，默认 0影响提示词强度与细小纹理的丰富程度。

精准放大

锐化强度、智能颗粒、精细细节均为 0 至 100。默认依次为 7、7、30。智能颗粒可减少过于平滑的观感，精细细节影响纹理、图案等微小细节。

费用与失败处理

两种模式采用相同的定价口径，所有展示、预扣、扣费及退款均以人民币计。使用账户余额计费，不消耗月卡额度。以提交前显示的当前图片与倍数价格为准；改换图片或倍数后须重新查看费用。

受理后的失败可能收费。参数或图片未通过校验时不收费；服务暂不可用且请求未被受理时不收费。任务一旦被上游受理，处理失败、缺少结果或长时间查询不到结果仍可能收费，不自动退款。提交结果不确定时请保留任务记录，避免重复提交。

每次放大分解为若干次 2 倍处理，并按每一步的输入总像素累计积分；同样的倍数，大图会消耗更多积分。费用以这些积分和当前人民币积分单价计算。价格示例中的 2、4、8 倍原图为 1000×1000，16 倍原图为 500×500，不能将示例当作所有图片的固定次价。

任务与下载

  1. 提交后可在“高清放大”作品分类查看进度。切换页面不会重新提交任务。
  2. 完成后预览结果，核对输出尺寸，并通过“下载原图”保存。
  3. 完成后系统会立即保存结果，保存完成后可在本站保留 72 小时。外部原始链接可能很快过期，若暂时无法保存请及时重试；原始链接过期后可能无法恢复。请使用本站任务下载入口，并尽快备份自己的作品。
  4. “结果待核对”表示提交结果尚不能确定；此时不要点击重新生成或更换请求标识来重复提交。

程序调用

使用本站图像令牌；供应商密钥不应出现在客户端。下例为精准放大，创意模式将模型名改为“创意放大”，并使用相应参数。

POST /v1/images/upscale
Authorization: Bearer <本站图像令牌>
Content-Type: application/json
Idempotency-Key: <本次操作唯一标识>

{
  "model": "精准放大",
  "image": "data:image/png;base64,<图片编码>",
  "scale_factor": 2,
  "flavor": "photo",
  "sharpen": 7,
  "smart_grain": 7,
  "ultra_detail": 30
}

先调用 POST /v1/images/upscale/estimate 预估；提交后根据 task_id 调用 GET /v1/images/upscale/tasks/{task_id} 查询，使用 GET /v1/images/upscale/tasks/{task_id}/download 下载。不得仅凭 HTTP 200 判断成功，请检查任务状态。cache_status=pending 表示正在保存，请继续轮询；ready 表示本站已缓存；expired 表示原始链接已过期且没有完成本站缓存。相同操作重试必须复用相同的幂等标识。

参数和限制依据接入接口文档（2026 年 11 月 2 日版）。提交页会以当前图片重新校验。
