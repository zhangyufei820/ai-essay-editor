# 媒体工坊 · 豆包绘图 5.5 接入说明

经典主题入口为 `/console/media-playground` → **豆包绘图 5.5**。填写创作要求后可以先查看费用上限。管理员核账并开放模型后，已获得图像权限的用户可在这里提交任务、查看历史和下载结果。

## 给用户的三种选择

| 我想做什么 | 我需要提供什么 | 成功后应看到什么 |
|---|---|---|
| 用文字画图 | 描述主体、场景、用途。在“成图设置”选择横图、竖图或方图，通过画幅预览确认构图 | 1 张图片。选择透明背景时使用 PNG |
| 参考图片改图 | 1–10 张参考图，再写清要改的地方和要保留的地方 | 1 张新图。再次修改时，可将上一次结果作为新的参考图 |
| 把海报拆成图层 | 1 张原图。可以让模型自动拆，也可以写出希望单独取出的元素 | 底图和各图层。开启文字识别时，规整文字还可能返回内容、位置和近似样式 |

文字生图和参考图改图支持自动画幅和 9 种固定比例，也可直接填写宽高。选择固定比例时，预览、请求和估价使用相同的像素尺寸。参考图可点击缩略图切换预览，拆图沿用原稿画幅。切换预览无需调用模型。画幅示例采用 Stefan van der Walt 的 CC0 照片。[图片来源与许可](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/_fetchers.py#L891-L905)

工坊接受 JPG、PNG，默认单张上限 20 MB、合计 60 MB，上传前在本机核对尺寸。普通参考图的宽和高都须至少 15 像素，拆图原图至少 262,144 像素；两种模式单图均不超过 3600 万像素，宽高比为 1:16 到 16:1。

普通生图的模型默认尺寸为 2K，拆图默认尺寸为 auto，模型默认拆图上限为 30。工坊在请求中**显式填写 1.5K**，拆图默认上限 **5 张（含底图）**，方便首次使用者先控制成本。普通生图每次最多输出 1 张。拆图的上限可调为 2–100，实际产物可能更少。普通编辑和图层拆分均使用生成端点，以 JSON 传入图片。

## 费用与对账

| 每张人民币单价 | 参考图 | 低档输出 | 高档输出 |
|---|---:|---:|---:|
| 星人用户价（兔子 default 报价 × 1.20） | 0.042 | 0.1092 | 0.1932 |
| 兔子 default / 官方优惠，报价倍率 ×1 | 0.035 | 0.091 | 0.161 |
| 兔子官方分组，原价 | 0.050 | 0.130 | 0.230 |
| 火山方舟直连公开价 | 0.050 | 0.130 | 0.230 |

**经过兔子**时，普通模式和拆图共用一套公式。1K、1.5K 或合法自定义尺寸的宽×高 ≤ 2,610,000 属低档。2K、拆图 auto、未指定尺寸和超出上述阈值的合法自定义尺寸属高档。这个请求的全部成功产物都用同一输出档位，含底图。输入图片从第一张计费。OCR 没有默认附加费。以最终账单为准。[兔子模型价目](https://api.tu-zi.com/pricing?tag=%E7%94%9F%E5%9B%BE&model=doubao-seedream-5-5-261028) · [拆图与退款说明](https://api.tu-zi.com/docs/use-cases/seedream55)

- 上限 = 输入张数 × 输入单价 + 最大产物数 × 请求档位输出单价。
- 成功结算 = 输入张数 × 输入单价 + 实际成功产物数 × 请求档位输出单价。
- 整个请求失败或零成功输出，费用为 0。上游拆图任一图层失败时按整单失败处理。提交时如有预扣，终态释放差额。连接超时、上游状态未知时，应保留待对账状态并用原任务标识查结果。
- 工坊将受理状态不明的任务保留为 `UNKNOWN`，原预扣仍挂在该任务下。确认上游无法交付后，系统管理员通过安全校验，调用 `POST /api/task/seedream/{task_id}/resolve-refund`，请求体为 `{"confirmed_undeliverable":true}`。退款跟随任务状态记录并幂等重试，用户可用原任务 ID 查询。
- 例如，选择 1.5K，把 1 张海报最多拆成 5 张，费用上限为 0.042 + 5 × 0.1092 = **¥0.588**。如果实际拿到底图和两个图层，合计 3 张，最终扣 **¥0.3696**，预扣差额 **¥0.2184** 会退回。相同任务选 2K 或 auto，上限为 **¥1.008**。
- 文生图没有参考图费用。1K 出一张图为 **¥0.1092**。使用一张参考图做同尺寸编辑为 **¥0.1512**。服务端从实际请求计算费用，将人民币金额一次换算为整数 quota。消费明细记录计价版本、输入输出张数、档位、预扣和结算额。[站内人民币计费约定](BILLING-CURRENCY-RMB.md)

**改为直连方舟**时，每张输出图按实际像素分别定档。≤ 261 万像素每张 0.13 元，超过 261 万至 463 万像素每张 0.23 元。拆图成功的底图和各图层可能跨档。以单张输入、1 张高档底图及 2 张低档图层为例，官方费用为 0.05 + 0.23 + 2 × 0.13 = **0.54 元**。[方舟官方定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)

## 提交、结果和开放流程

1. 文生图填写提示词。改图先上传参考图，再说明要改和要保留的部分。拆图上传一张原图，可以省略提示词。透明背景使用 PNG。文字识别可用于提取图层里的文字。[方舟模型介绍](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh) · [图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)
2. 三种模式共用站内图像任务接口。模型转发使用非流式 `POST /v1/images/generations`。返回结果保留图片顺序、图层及上游提供的位置和文字信息。用户可以在媒体工坊的历史记录中重新打开已有任务。
3. 运维使用 `scripts/configure_seedream55_channel.py --stage` 暂存渠道。指定渠道的管理员图像令牌运行一次最小测试。核对上游消费记录、站内流水和钱包差额后，使用 `--publish ADMIN_LOG_ID` 开通模型广场和托管图像令牌。月卡的模型范围和自定义令牌限制继续按各自的权益规则执行。
