# 媒体工坊 · 豆包绘图 5.5 接入说明

经典主题入口为 `/console/media-playground` → **豆包绘图 5.5**。这一版用于填写创作要求、校验图片与试算费用。参考价按 2026-11-20 读取的兔子模型价目，零售价和分组权益须在正式开放前确定。

## 给用户的三种选择

| 我想做什么 | 我需要提供什么 | 成功后应看到什么 |
|---|---|---|
| 用文字画图 | 描述主体、场景、用途。想画横图或竖图，可以写进描述 | 1 张图片。选择透明背景时使用 PNG |
| 参考图片改图 | 1–10 张参考图，再写清要改的地方和要保留的地方 | 1 张新图。再次修改时，可将上一次结果作为新的参考图 |
| 把海报拆成图层 | 1 张原图。可以让模型自动拆，也可以写出希望单独取出的元素 | 底图和各图层。开启文字识别时，规整文字还可能返回内容、位置和近似样式 |

工坊预览接受 JPG、PNG，默认单张上限 20 MB、合计 60 MB，上传前在本机核对尺寸。普通参考图的宽和高都须至少 15 像素，拆图原图至少 262,144 像素；两种模式单图均不超过 3600 万像素，宽高比为 1:16 到 16:1。

普通生图的模型默认尺寸为 2K，拆图默认尺寸为 auto，模型默认拆图上限为 30。工坊在请求中**显式填写 1.5K**，拆图默认上限 **5 张（含底图）**，方便首次使用者先控制成本。普通生图每次最多输出 1 张。拆图的上限可调为 2–100，实际产物可能更少。普通编辑和图层拆分均使用生成端点，以 JSON 传入图片。

## 费用与对账

| 每张人民币单价 | 参考图 | 低档输出 | 高档输出 |
|---|---:|---:|---:|
| 兔子 default / 官方优惠，当前账户倍率 ×1 | 0.035 | 0.091 | 0.161 |
| 兔子官方分组，原价 | 0.050 | 0.130 | 0.230 |
| 火山方舟直连公开价 | 0.050 | 0.130 | 0.230 |

**经过兔子**时，普通模式和拆图共用一套公式。1K、1.5K 或合法自定义尺寸的宽×高 ≤ 2,610,000 属低档。2K、拆图 auto、未指定尺寸和超出上述阈值的合法自定义尺寸属高档。这个请求的全部成功产物都用同一输出档位，含底图。输入图片从第一张计费。OCR 没有默认附加费。以最终账单为准。[兔子模型价目](https://api.tu-zi.com/pricing?tag=%E7%94%9F%E5%9B%BE&model=doubao-seedream-5-5-261028) · [拆图与退款说明](https://api.tu-zi.com/docs/use-cases/seedream55)

- 上限 = 输入张数 × 输入单价 + 最大产物数 × 请求档位输出单价。
- 成功结算 = 输入张数 × 输入单价 + 实际成功产物数 × 请求档位输出单价。
- 整个请求失败或零成功输出，费用为 0。上游拆图任一图层失败时按整单失败处理。提交时如有预扣，终态释放差额。连接超时、上游状态未知时，应保留待对账状态并用原任务标识查结果。
- 例如，优惠档 1.5K 拆 1 张海报，上限 5 张。预计最高 0.035 + 5 × 0.091 = **0.490 元**。实际返回底图和 2 个图层时共 **0.308 元**，若已按上限预扣，应释放 **0.182 元**。改为 2K 或 auto，同一上限为 **0.840 元**。
- 成本配置和正式零售配置分别维护。当前界面的试算不产生账务流水。正式接入应由服务端读取用户可用分组和价表，不能使用浏览器提交的单价或总额。保存每次请求的价格版本、档位及人民币单价，依项目统一规则一次换算 quota，使用既有任务标识幂等结算。[站内人民币计费约定](BILLING-CURRENCY-RMB.md)

**改为直连方舟**时，每张输出图按实际像素分别定档。≤ 261 万像素每张 0.13 元，超过 261 万至 463 万像素每张 0.23 元。拆图成功的底图和各图层可能跨档。以单张输入、1 张高档底图及 2 张低档图层为例，官方费用为 0.05 + 0.23 + 2 × 0.13 = **0.54 元**。[方舟官方定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)

## 正式生成的接线点

1. 服务端配置模型 `doubao-seedream-5-5-261028`，经已授权的渠道发送 `POST /v1/images/generations`（原生为 `/api/v3/images/generations`），JSON、非流式。将本地选中的图片上传到现有受控媒体存储，生成时传可读取的图片 URL。表单中的示例地址仅用来预览请求格式，密钥只留服务端。
2. 普通模式校验提示词，参考图编辑校验张数。拆图请求须启用 `layer_decomposition`、恰好传 1 张图片，可以省略提示词。拆图选项为 `layer_decomposition_options.max_images` 和 `text_recognition`。拆图省略 `background`，`output_format` 仅控制底图，各图层为 PNG。普通透明输出使用 PNG，不传通用遮罩、组图数或流式字段。[方舟模型介绍](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh) · [图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)
3. 当前 `controller/playground_image_task.go` 的通用入口要求非空提示词，成功路径的 `cacheFirstPlaygroundImageTaskResult` 只取首图。启用此模型时须有单独的请求校验，并完整保存 `data[]`。按任务及产物索引或图层序号保存，不能按 URL 去重。同一 URL 也可能对应多个图层条目。
4. 在历史详情中分别显示底图、各图层预览与下载，保留 `z_index`、`bounding_box`、名称、描述和可选 `text_recognition`。没有文字识别信息的图层仍是有效产物。上游临时链接应及时转存；重试转存只恢复已有结果，不再生图。
5. 正式放开生成前，在测试分组逐项核对三种入口、分组可用性、实际返回张数、全失败退款、重复回调和账务金额。特别对照上面的 0.490 / 0.308 / 0.182 元例子，用日志还原输入费、输出费和差额。未配置渠道或零售价时，入口保持为表单预览。
