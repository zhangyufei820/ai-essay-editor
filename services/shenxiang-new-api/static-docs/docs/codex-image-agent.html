星人 API 文档中心第三方接入说明
本地 Codex · 图像助手

在 Codex 里直接生成图片

只需安装一次。之后像聊天一样描述你想要的图片，Codex 会完成生成或修改，并把图片保存在当前项目文件夹。

第一次安装：只做这 4 步

1
打开终端

Windows 打开 PowerShell；Mac 打开“终端”。

2
复制图像生成令牌

进入星人 API 控制台的“第三方接入”，复制“星人图像生成令牌”。不要把它发给任何人。

3
复制并运行这一条命令
npx -y xingren-codex-image-mcp install

出现提示后粘贴令牌并按回车。粘贴内容不会显示，这是正常的。

4
重启 Codex

完全退出后重新打开 Codex，即可开始使用。

如果终端提示找不到 npx，先安装 Node.js 长期支持版，重新打开终端后再执行第 3 步。

怎么和 Agent 说

不需要记命令，也不需要输入令牌。直接把下面的话发给 Codex 即可。首次调用时若 Codex 请求确认，选择允许。

帮我生成一张课程封面图：
一位中学生在书桌前学习，明亮现代插画风，横版，无文字。
帮我生成一张小红书配图：
主题是“如何提高专注力”，温暖、简洁、留出标题位置，竖版。
修改项目里的 poster.png：
只把背景改成傍晚校园，人物、姿势和文字都不要变。

生成的图片会保存到当前项目的 generated-images 文件夹。修改图片时，请先把原图放进当前项目；目前支持 PNG，单张原图或遮罩图片不超过 4MB。

遇到问题怎么办

我看不到图像工具
在 Codex 输入 /mcp。看到 xingren-image 就表示连接成功；若没看到，请重启 Codex 后再试。
提示令牌无效或额度不足
回到控制台重新复制“星人图像生成令牌”，再运行一次安装命令。不要使用文本令牌或视频令牌。
图片没有生成成功
稍等一分钟后重试；也可以把描述写得更具体，例如补充主体、画面比例、风格和“不要出现文字”等要求。
我想重新设置令牌
再次运行 npx -y xingren-codex-image-mcp install，按提示粘贴新的图像生成令牌即可。

安全提醒：令牌只保存在你的电脑上。不要发送令牌、截图令牌，也不要把令牌写进项目文件。
