安装后先做这 5 步
  1. 打开原版 Codex App，确认能正常进入界面，然后关闭。
  2. 打开 Codex++ 管理工具。
  3. 进入中转注入/API 配置页，选择 OpenAI-compatible。
  4. 复制右侧 Base URL、API Key 和模型名。
  5. 应用配置后，日常从 Codex++ 启动。
