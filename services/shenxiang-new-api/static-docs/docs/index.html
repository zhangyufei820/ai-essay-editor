三步完成配置

不需要理解复杂术语。只要知道自己用的是普通客户端，还是 Claude Code。

1

打开控制台

登录后进入令牌页面，新建一个用于当前工具的 API Key。建议一个工具用一个 Key，后续更好管理。

2

复制三项配置

复制 Base URL、API Key 和模型名。普通客户端用 /v1，Claude Code 用 /claude。

3

粘贴并测试

在客户端设置页保存配置，发送一句“你好”。能收到回复，就说明接入成功。

¥500 月卡这样使用

月卡开通后，不要创建普通 Key。到充值中心点击“创建月卡专用 API Key”，这个 Key 会固定走月卡订阅额度，并只显示月卡专供通道里的模型。

1

确认月卡已生效

进入控制台充值中心，找到我的订阅。看到 ¥500 月卡、到期时间、每日额度和月总额度进度，就说明已经开通。

2

创建专用 Key

在“我的订阅”右侧点击“创建月卡专用 API Key”。系统会自动生成或更新一个名为 ¥500 月卡专用 的 Key。

3

按模型列表选择

用月卡专用 Key 请求 /v1/models，返回的就是月卡专供通道当前开放的全部模型。客户端只填列表里显示的模型名。

入口在哪里

不要在普通令牌页面手动创建月卡 Key。普通 Key 会按普通钱包/模型计费逻辑走；月卡专用 Key 要从充值中心的一键按钮创建。

1
打开充值中心
进入 https://api.aiphui.top/console/topup。
2
看我的订阅
确认 ¥500 月卡处于生效中，并能看到日额度、月额度和到期时间。
3
点击创建
点击“创建月卡专用 API Key”。创建成功后 Key 会自动复制到剪贴板。

推荐优先使用 Responses API。月卡专用 Key 会强制走订阅计费，模型列表会读取月卡专供通道里的全部可用模型。

  -d '{

进度条怎么看

月卡按官网等值美元额度展示进度。当天额度用完会暂停到次日自动恢复；月总额度用完会暂停到续费或重新购买。

绿色
额度正常，可以继续调用。
黄色
接近日额度或月额度上限，建议减少大请求。
红色
额度已达上限，系统会限制月卡调用。

调用前自查

最关键的一句话 月卡用户直接创建“月卡专用 API Key”；不要使用普通 Key。模型名以这个 Key 请求 /v1/models 的返回结果为准。
1
Base URL
月卡专用 Key 也填写 https://api.aiphui.top/v1。
2
接口优先级
优先使用 /v1/responses；旧客户端可以继续用 /v1/chat/completions。
3
出错时
403 先检查是否已开通月卡、是否用了月卡专用 Key、模型是否来自 /v1/models。

常见问题一眼看懂

先看错误提示，再按下面处理。大多数配置问题都能在一分钟内定位。

401

Key 不正确

重新复制 API Key，确认没有多余空格，也没有把别的工具的 Key 填进来。

403

模型未开通

换用控制台里能看到的模型，或联系客户支持开通对应模型权限。

余额

额度不足

进入控制台钱包页面充值或兑换额度，到账后再发起请求。

重试

服务繁忙

稍后再试，或把请求内容缩短一点。长文本建议开启流式输出。

价格、充值与安全

配置成功后，实际消耗以控制台价格和钱包记录为准。不要把 API Key 贴到公开网页、公开仓库或聊天群。

查看公开价格 打开钱包

配置前检查

  • Base URL 和工具类型匹配。
  • API Key 只复制给自己的客户端。
  • 模型名来自控制台可用模型。
  • 余额充足，测试请求尽量短。

不会配置时，直接这样问

把你使用的工具名、系统、截图里的报错发给客户支持。说明“我想接入星人 API”，并贴上你看到的错误码，不需要发送完整 API Key。
