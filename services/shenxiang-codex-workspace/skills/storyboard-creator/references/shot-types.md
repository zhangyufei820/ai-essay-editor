# Shot Types

Use shot types deliberately; do not over-label.

| ID | 中文 | Use |
|---|---|---|
| `wide` | 全景 | Establish location, scale, relationship between people and space. |
| `medium` | 中景 | Dialogue, teaching scenes, human action with context. |
| `close_up` | 特写 | Emotion, important face reaction, object emphasis. |
| `extreme_close_up` | 大特写 | Tiny details: eyes, hands, pen tip, screen text. |
| `over_the_shoulder` | 过肩 | Conversation, tutoring, screen or paper review. |
| `pov` | 主观镜头 | User sees through character/student/teacher perspective. |
| `aerial` | 俯拍/航拍 | City, campus, large environment, planning view. |
| `insert` | 插入镜头 | Object, note, graph, document, prop, UI detail. |

Recommended rhythm:

- Hook: wide or close_up.
- Explanation: medium + insert.
- Emotional beat: close_up.
- Resolution: wide or medium.
