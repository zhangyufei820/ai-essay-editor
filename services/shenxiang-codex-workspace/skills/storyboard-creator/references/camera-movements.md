# Camera Movements

Use one dominant movement per shot.

| ID | 中文 | Use |
|---|---|---|
| `static` | 固定镜头 | Clear explanation, diagrams, calm emotional moment. |
| `push_in` | 推镜 | Reveal importance, focus attention, emotional build. |
| `pull_out` | 拉镜 | Reveal context, loneliness, scale, conclusion. |
| `pan` | 横摇 | Reveal a room, classroom, timeline, sequence. |
| `tilt` | 俯仰 | Reveal height, document-to-face, object-to-person. |
| `tracking` | 跟拍/移动 | Follow action, walking, process, transformation. |
| `handheld` | 手持感 | Urgent, documentary, personal vlog style. |
| `crane` | 升降 | Grand reveal, stage-like transformation. |
| `orbit` | 环绕 | Dramatic hero moment, product reveal, transformation. |

Video prompt phrasing:

- `A slow push-in toward ...`
- `Camera tracks gently alongside ...`
- `Static camera, subtle natural movement only ...`
- `A smooth pan reveals ...`
