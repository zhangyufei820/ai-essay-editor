# 连接你的 Agent

你不需要复制 API Key，也不需要把 Key 发给任何人。

## 连接前准备

1. 先登录星人 API 控制台。
2. 在你使用的 Agent 里打开“设置”。
3. 找到“工具连接”或 “MCP”。
4. 选择“添加远程服务”。
5. 根据 Agent 的提示添加服务。

连接后，你可以直接说：

- “帮我写一篇课程招生文案。”
- “生成一张简洁的课程封面图。”
- “生成一段 8 秒的课程宣传视频。”

第一次使用时，可以先说：“检查星人服务是否已连接。”
如果 Agent 回答“已连接”，文本、图片和视频都已经准备好，不需要分别安装。

## Codex

Codex 当前的“自定义 MCP”页面不会自动打开网页登录授权。请按下面做：

1. 先在浏览器打开：`https://api.aiphui.top/codex/agent/codex`，登录后点击“生成连接码”。
2. 打开 Codex 的“设置 → 插件 → MCP → 连接至自定义 MCP”。
3. 名称填写“星人工具”，类型选择“流式 HTTP”。
4. URL 填写：`https://api.aiphui.top/codex/mcp`。
5. 在“标头”增加一行：键填写 `Authorization`，值填写 `Bearer ` 后再粘贴刚刚复制的连接码。
6. 保存。不要填写“Bearer 令牌环境变量”，也不要填写其他标头。

连接码不是账户 Key，只能调用星人工具。它会在 90 天后失效；你随时可以回到连接码页面点击“断开 Codex”，旧连接码会立即失效。

## WorkBuddy

只有支持“远程 MCP”或“HTTP MCP”的 WorkBuddy 版本可直接连接。若设置里只有“本地命令”，说明该版本暂不支持一键网页授权；请等待客户端更新，不要粘贴账户 Key。

## 安全说明

- Agent 只能调用你确认授权的文本、图片和视频工具。
- Agent 看不到你的账户 Key、余额明细或服务内部信息。
- 连接可随时在 Agent 中删除；删除后该 Agent 不能继续调用服务。
- 遇到失败时只会显示可理解的提示，不会暴露系统地址、密钥或内部报错。

## 给开发者的 API 接入

可以使用同一套网页登录授权体系，但 API 必须申请单独的权限范围。MCP 连接令牌不能用于通用 API 调用；这样可以在撤销、限额和权限管理上保持清晰边界。

## 如果 Agent 自己不能聊天

这通常表示 Agent 本身还没有配置它自己的模型服务。星人工具已经连接，但 Agent 的聊天功能属于它自己的设置，星人无法读取或自动修改。请在 Agent 的首页按提示完成它自己的登录或模型设置，然后再回来使用星人工具。
