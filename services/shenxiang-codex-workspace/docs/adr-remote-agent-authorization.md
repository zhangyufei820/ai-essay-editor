# ADR：远程 Agent 授权

## 背景

普通用户不应复制 API Key、配置终端或知道服务链路。Codex、Claude Code 等 Agent 需要一套可撤销、可过期、按账户权限执行的连接方式。

## 决定

使用远程 Streamable HTTP MCP，并由星人网页登录态完成 OAuth 2.1 授权。

- 客户端使用 PKCE 获取短期访问令牌和可轮换刷新令牌。
- 服务端只保存完成本次受控调用所需的账户上下文；不会把账户 Key 返回给客户端。
- MCP 只暴露产品级工具：文本助手、图片生成、连接状态。
- 图片以 MCP 图片内容返回，不返回外部结果地址。
- 所有工具错误经统一脱敏后返回；日志也不得记录授权令牌或外部响应原文。

## 后果

- 用户只需在 Agent 的 MCP 连接界面粘贴一次星人连接地址，然后在网页点击授权。
- 每个客户端可在账户页面撤销连接；访问令牌失效后需用刷新令牌续期。
- 不支持 MCP 的客户端不能被网页自动改写配置，仍需由该客户端提供导入入口或安装器支持。
- API 访问可复用相同授权层，但必须另设明确 scope，不能把 MCP 令牌当成通用 API Key。
